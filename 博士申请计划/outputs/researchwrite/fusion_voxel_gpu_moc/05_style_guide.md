# Style guide

- Chinese academic outline with numbered sections and compact tables for question-method-validation mapping.
- No adequate original applicant prose available from style retrieval; use explicit academic style requested by user.
- Retain distinction among documented result, inference, proposed hypothesis and target.
- Avoid 首创/填补空白/国际领先/显著 unless narrowly evidenced.
- Minecraft is an intuition only, not the academic title or method claim.
- Bibliography: numbered, journal year vs online DOI year reconciled; primary source links.
- Do not create a cloud Page. Local files follow researchwrite format and existing workspace destination.
