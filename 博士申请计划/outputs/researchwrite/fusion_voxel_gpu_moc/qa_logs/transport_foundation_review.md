# 输运数值方法基础审查

审查日期：2026-10-18。审查对象：00_scope、01_research_canon、02_evidence_table、03_argument_map、04_section_contracts。角色：独立输运数值方法可行性审查；不是结果复现或文献优先权判定。

**结论：基础评分 8.2/10，可进入大纲写作。** 主问题已从“把 MOC 放到 GPU”收敛到“复杂几何、响应精度、显存和端到端成本之间的可验证权衡”，并正确将混合减方差列为条件性扩展。以下八项需体现在方法和范围中；其中第 1、3、4 项关系核心路线成立，第 7 项关系扩展的数学正确性。现有基础不足以声称已经获得通用性能优势。

## 1. 体素追踪算法不是完整的输运离散

- **已有依据：** canon 正确区分了体素表示与 MOC；官方 MOC 推导明确，沿线解析积分之后还需要空间/角度积分和源更新。[OpenMC 方法文档](https://docs.openmc.org/en/stable/methods/random_ray.html)。此处只借其 MOC 推导，不把随机射线统计性质套用于确定性 MOC。
- **审查推断：** DDA 能正确找到界面，不等于有限数量轨迹能覆盖所有源区、给出一致的体积/角权或保持全局粒子平衡。AMR 后小体素更易漏采样；真空流道恰可能是响应敏感区。只报告网格收敛不足以识别轨迹积分误差。
- **建议修正：** 大纲增加“全三维轨迹布置—积分权重—源区覆盖—守恒校验”。明确默认材料区与平源区可先重合，但概念不等同；轨迹间距和角度求积应独立收敛。局部加密时检验轨迹覆盖和权重一致性。
- **可证伪检验：** 在固定网格上改变轨迹间距、角阶和轨迹相位；记录未覆盖源区比例、源—吸收—泄漏平衡残差及响应变化。如果网格继续细化而误差停滞或相位敏感增强，就不能把该路线判为收敛成功。

## 2. 几何响应关系不能退化为体积分数或表面距离指标

- **已有依据：** argument map 已包含弦长、光学厚度和空腔连通性，方向正确。
- **审查推断：** 同样材料体积误差可产生完全不同的穿透响应；薄壁丢失和孔道闭合属于拓扑变化。总体体积守恒甚至可能掩盖小但关键的直视通道。
- **建议修正：** 将 RQ1 写成“哪些几何/输运指标能识别响应敏感部位，并在未参与调参的几何上选择足够细的局部表示”。对每个指标保留失效边界，不承诺一个全局误差上界。若采用响应权重/伴随权重，应说明初始粗解可能漏掉通道，保留纯几何薄层与连通性检查。
- **可证伪检验：** 用曲面夹层、旋转窄缝、直/弯管道组成参数族，改变壁厚/体素尺寸、缝宽/体素尺寸、曲率和方向；留出部分参数检验。固定响应容差和显存上限，若局部策略在留出集不能较均匀细化降低成本，或出现容差外的漏判，则该策略失败。

## 3. 真空是核心工况，不能用小截面填充掩盖数值问题

- **已有依据：** 经典平源 MOC 公式常出现 Q/Σt，直接代入真空会产生未定义形式；但其解析极限存在。
- **审查推断：** 聚变堆等离子体区、真空室和流道使 Σt→0 成为必要路径。浮点消减、极小截面代替真空和混合精度可能制造非物理衰减，且这种误差会累积到深穿透响应。
- **建议修正：** 在大纲写“真空/光学薄区稳定的特征积分及源项平均”，无需展开程序实现。可用 ψout=ψin exp(-τ)+QℓF(τ)，τ=Σtℓ，F(τ)=(1-exp(-τ))/τ，F(0)=1，说明极限 ψout=ψin+Qℓ。
- **可证伪检验：** 无源真空段恒通量、有源真空段线性增长、极小 τ 到有限 τ 连续过渡；再测真空—屏蔽交界。稳定性和精度未通过前不进入 GPU 混合精度优化。

## 4. 聚变固定源物理需要能量—角度耦合，且可包含中子倍增

- **已有依据：** 官方多群输运说明将 (n,2n)、(n,3n) 等二次中子产生纳入转移处理；OpenMC 随机射线文档也将各向同性源近似列为误差来源。[OpenMC 方法文档](https://docs.openmc.org/en/stable/methods/random_ray.html)。这些是物理/方法边界，不意味着所有比较程序都有相同支持。
- **审查推断：** 仅用各向同性散射验证反应堆式基准不足以支持 14 MeV 聚变屏蔽适用性。Be/Pb 等增殖材料下，“固定源”不应被解释为没有中子倍增。群常数凝并误差也可能大于空间几何误差。
- **建议修正：** 以各向同性一群例题起步，但把多群各向异性散射及必要的 (n,xn) 转移作为核心物理验证，而非最终可选功能。散射阶次、群结构与截面来源分开收敛；先同多群数据比较，再与连续能结果比较综合误差。
- **可证伪检验：** 在同一体素几何、同一群常数与散射阶次下与多群 MC/可信参考解比较；若仅连续能 MC 不一致，不能直接归咎于 MOC。对 OpenMC random ray 等基线需注明版本及其各向同性近似，分别做匹配物理的算法比较和各自完整流程的工程比较。
- **范围澄清：** 核心目标响应宜限定中子通量及反应率（可含氚产生或阈反应）。总核热、停堆剂量分别涉及光子与活化链，不应在中子单粒子范围下承诺完整预测。

## 5. GPU 并行单位及迭代耦合要明确

- **已有依据：** argument map 已否定“空间体素全部独立更新”，并采用轨迹—角度—能群批处理。
- **审查推断：** 冻结源和给定入射边界时，不同完整轨迹可并行，而同一轨迹的前后段有输运依赖；对同一源区的累积有写冲突。跨能群转移、散射源更新、反射/周期边界和区域分解又会引入耦合。把能群全部并行可能增加迭代次数。
- **建议修正：** 明确比较对象是“冻结源扫描、通量累积、源/能群迭代和收敛加速”的组合。优先单 GPU；多 GPU 与复杂域分解在问题尺寸证明必要后开展。AMR 的分支开销、低占用和负载不均必须计入。
- **可证伪检验：** 同一误差/残差终止标准下同时报告单次扫描耗时、迭代次数、总耗时和峰值显存。扫描快而总时间慢即为失败；不得更换较松收敛标准补救。低阶加速在空腔和 AMR 上也须验证稳定性，不预先假定扩散加速必然有效。

## 6. 性能问题应限定基线和 Pareto 区域，不承诺全面优越

- **已有依据：** 已采用同等响应精度的端到端成本，且禁止单核/内核夸张加速比。
- **审查推断：** “优于现有一般几何输运路线”仍过宽；可获得的软件和硬件未确定，跨语言、跨物理模型或不同调参努力会使比较难以解释。
- **建议修正：** 至少设置同一算法的优化多核 CPU/单 GPU 配对、均匀体素/选择性细化配对，再选择一种可复现的一般几何参考路线。软件性能比较和数值正确性参考可由不同工具承担，不必强求所有代码均提供 GPU 版本。
- **可证伪检验：** 给定目标响应集合 R、容差 ε_R 和显存预算 Mmax，比较达到目标的最低总时间，展示时间—误差—显存曲线和无优势区域。参数搜索成本不混入单次正式求解，但几何转换、轨迹生成、传输和初始化计入并单列可复用项。不得只展示有利样例。

## 7. 伴随必须对应离散算子；角度信息不足是可识别的扩展边界

- **已有依据：** argument map 已提出加权离散对偶和响应恒等式；FW-CADIS 和角度相关变体有既有工作。官方 OpenMC 文档确认其权窗生成使用内部随机射线前向/伴随计算。[OpenMC 减方差方法](https://docs.openmc.org/en/stable/methods/variance_reduction.html)。
- **审查推断：** 反转轨迹或转置群转移矩阵本身不足以证明离散伴随正确。体积/角度权、边界映射、累积归约和插值均属于离散算子。连续层面的相互易定理不能替代程序的离散验证。
- **建议修正：** 定义离散内积和相应伴随，例如在合适的同空间表示下 A†=M^-1 A^T M；重点验证小系统的代数对偶关系及多响应身份，之后才生成权窗。空间—能量标量重要性先作为基线，角度修正只在流道算例证明其必要后开启。
- **可证伪检验：** 随机向量离散对偶残差、前向/伴随响应一致性、局部 CADIS 与全局 FW-CADIS 分别验证。若局部通量精度提高而 MC FOM 无改善，接受“重要性保真度与确定论精度不单调”的结论，而非强行追求更细确定论解。

## 8. 混合减方差的评价应覆盖统计可靠性和摊销门槛

- **已有依据：** 当前计划包含总成本、支撑保持和 MC 权重守恒，是正确起点。
- **审查推断：** 深穿透情况下少量非零历史可能导致看似很小/很大的误差条；单次运行 FOM 并非可靠结论。过窄权窗还会产生大量分裂和长历史，恶化 GPU/CPU 负载。确定论权窗可粗糙，但不能以漏掉贡献路径为代价。
- **建议修正：** 预先定义目标 tally、统计精度目标和多次独立运行；与 analog/现有 MC 减方差、MAGIC、可用 random-ray FW-CADIS 比较。总成本包括群常数准备、前向/伴随、映射/权窗和 MC。
- **可证伪检验：** 同等统计精度下比较总时间，并比较多次估计与可信参考的置信区间覆盖；对全局目标报告高分位或最差相对误差，而非仅平均值。分别给一次求解及多次复用的成本；若预处理成本仅能在多次复用后回收，应报告临界复用次数。保留 MC 原几何，防止“同一错误体素几何自洽”被误当成真实几何验证。

## 可直接纳入大纲的研究问题表述

1. **几何问题：** 在薄层、狭缝和弯曲流道中，哪些可计算几何/光学指标能识别响应敏感区域，使局部体素表示在指定响应容差下比均匀细化减少时间和显存；在哪些拓扑或角度条件下失效？
2. **并行问题：** 在固定物理模型、响应误差和显存预算下，在线追踪、批处理、通量累积与迭代加速如何共同决定 GPU 端到端成本；局部加密收益何时被调度和迭代开销抵消？
3. **条件性耦合问题：** 在保留最终 MC 原始几何和统计正确性的前提下，前向/伴随近似精度达到何种程度即可形成有效权窗；额外预处理在何种响应类型和复用次数下优于现有减方差流程？

## 缺失输入、阶段门槛与评分说明

- **仍缺输入：** 申请人已有基础；导师可复用模块与合作意向；GPU/软件许可；可公开基准及输入文件；目标群库与响应定义。不得在可行性中写成已经具备。
- **建议阶段门槛：** 第一阶段完成守恒、真空极限、角度/轨迹/空间独立收敛和多群物理核验；第二阶段证明至少一个可复现的精度—成本优势区间并说明失效区间；第三阶段有可靠前向解后才验证伴随/权窗。第二阶段若无优势，应形成适用边界与改进准则，并减少多 GPU/耦合范围，避免四年任务失控。
- **评分分项（审查判断）：** 问题明确性 8.5，物理完整性 7.7，数值验证闭环 8.4，性能比较可解释性 8.2，四年可行性 8.2，创新边界 8.3；综合约 8.2。物理与离散细节写入大纲后可保持高于 7.5 的基础通过线；这不是论文新颖性已被证明的评分。
