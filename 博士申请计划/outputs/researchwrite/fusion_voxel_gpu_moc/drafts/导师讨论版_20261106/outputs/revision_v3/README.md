## 独立重建

依赖及本轮工具环境见[requirements.txt](requirements.txt)与[环境清单](qa/生成环境清单.json)。需要Python 3.12、md-to-word-docx 3.3.2、LibreOffice、Cairo及项目字体。`DOCX_RENDERER`可指向documents技能的render_docx.py。

在本目录运行：

```bash
python scripts/rebuild_v3.py
```

所有输入与输出均在V3，保护检查只读V2/原件。`safety_v3.py`拒绝解析到V2的写入根。新克隆不包含本机忽略的下载缓存，可使用`python scripts/rebuild_v3.py --portable`；该模式核对145个Git基准文件，明确不冒称已检查缺失的本地缓存。本次完整本地1949项验收另有前后记录，不以便携模式代替。
