# V3生成与一致性审查闭环

独立审阅者首轮指出数学结构flatten、角色级别、书目循环证据、缺少PDF与humanMD硬门等问题。根代理逐项补齐，独立审阅者随后实际只读复算并在原报告前置修正后结论；历史问题保留，不冒称从未出现。

最终采用独立MathML/OMML结构投影，分数、上下标、重音与算子限参与比较；humanMD也比较65处AST。普通Unicode上下标在文本规范化中保留区别。一般数字括号不任意排序。角色与标题级别参与段落比对。63项书目按corpus及实际BibTeX逐字段核对，并检查63个可见URL与真实链接目标。Word六图依序与PNG源字节相同，PDF六图数量与宽高比核验。

PDF绘制字符按顺序与Word严格比较，重音以相同的前置标记表示；只对相邻Unicode上标字形依据真实x坐标恢复字体分批绘制顺序。任何正文字符和标点残差均失败。本轮确实定位并修复一处行末漏绘逗号，不将它作为无关格式差异丢弃。页眉脚、目录和3处续表重复表头有明确排除记录。

敏感性测试是10项内存比较器断言，覆盖丢字、重复、标题角色、表格单元格顺序、分数、上下标、重音、Unicode脚本与数字括号，不声称做过10次篡改交付物后的端到端实验。最终生成链另在隔离副本完整运行，并通过同一hard-fail验收门。主交付Word/PDF字节未被重建测试覆盖。

最终报告/JSON已刷新到10项断言、393个块、196表格单元格、65数学结构、63参考文献和32273个PDF规范字符。零残差才返回0；源码重组与实际图、目录及书目链接也均检查。用户已批准单列V2的.DS_Store差异，所有科研文件仍按字节不变验收。
