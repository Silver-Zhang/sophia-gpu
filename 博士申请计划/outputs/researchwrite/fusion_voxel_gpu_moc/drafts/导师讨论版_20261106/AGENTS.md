# 用户审阅版本约束

- 当前Word及`review_archive/`中的原件是删改和批注的权威证据，禁止接受或拒绝修订、清除批注、覆盖原件。
- 用户明确要求：先提取、核对并保留全部删改和批注，再更新生成源文件。未经用户确认，不允许通过重新生成Word恢复已删除内容。
- `review_state.json`的`regeneration_approved`当前为false。没有后续明确用户确认，禁止改为true，禁止运行其他导出路径绕过`review_guard.py`，禁止生成替代Word。
- 现行源以修订后保留的文字为准：删除内容只能出现在审计归档和Git历史中，不得从旧源、旧摘要、旧题注、旧章节断言或硬编码回填。
- 保留原批注意见和上下文；批注的合节、补充文献、修改语言或绘图要求尚未执行，不能擅自标为已解决。
- `sources_ch01.md`—`sources_ch06.md`、`frontmatter.md`为现行正文源。图、表和题注在章节源中显式保留，不再隐式插入。`table_sources.md`和`tables/`是派生快照。
- 更新源文件与重新生成Word是两项不同操作。源同步不得修改当前Word、PDF或此前逐页渲染；旧自审报告只适用于当时的初稿。
