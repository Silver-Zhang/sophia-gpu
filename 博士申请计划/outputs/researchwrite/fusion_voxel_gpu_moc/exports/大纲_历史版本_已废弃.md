# 面向聚变堆复杂几何中子输运的体素化特征线方法与 GPU 并行研究

博士科研计划书大纲

本研究拟针对聚变堆曲面材料界面、薄层结构与贯穿孔道并存条件下的三维固定源中子输运，研究体素化几何近似对目标响应的影响，构建兼顾响应精度、显存需求与计算时间的 GPU 特征线求解方法。在核心算法得到验证后，进一步评估其作为正向与伴随重要性求解器用于蒙特卡罗减方差的适用条件。研究将围绕几何表示、输运离散、并行执行与响应验证之间的关系展开。

## 一 研究背景与意义

### 1.1 聚变堆中子学分析的需求与对象

- 以 D–T 聚变源条件下包层、屏蔽结构及其贯穿孔道的中子输运为对象，说明约 14 MeV 源中子、多材料非均匀分布与大范围衰减带来的计算需求。
- 将主要输出限定为中子通量谱、泄漏以及指定区域的反应率；在相应材料与核数据条件具备时，考察氚产生反应率。局部包层模型的氚产生结果不直接等同于全堆氚增殖比。
- 联系方案筛选、几何参数调整和局部精细评估，说明为何需要兼顾建模效率、计算精度与重复计算成本。聚变输运基准及核数据研究作为背景依据[1–2]。

### 1.2 复杂几何与计算组织之间的矛盾

- CAD/CSG 能保留复杂材料界面，但几何查询、射线求交与数据组织可能增加输运成本；已有 CAD 蒙卡工作说明，复杂几何并非只有体素化一条处理路线[1]。
- 规则体素有利于建立直接索引和规则遍历；另一方面，曲面阶梯化、薄层遗漏及孔道闭合可能改变粒子的实际传播路径。
- 均匀加密能够提高几何分辨率，但三维单元数、特征线分段数量和通量存储随之增长。局部加密减少单元数，也可能增加 GPU 分支与负载不均。

本节需要引出的核心矛盾是：**怎样在目标响应误差可接受的前提下，保留体素几何带来的并行效率，而不以破坏关键输运路径为代价。**

### 1.3 选择 MOC 与 GPU 的理由

- MOC 沿特征线积分输运方程，允许将几何追踪与分段输运计算组织为可复用的计算过程；已有 OpenMOC、三维 GPU-MOC 和非结构三维 MOC 为研究提供了基础[3–6]。
- GPU 提供轨迹、角方向与冻结源条件下能群层面的并行机会，但同一轨迹内的递推、源更新和通量累积仍有依赖与通信成本。
- 因而研究重点是体素表示与输运算法的协同设计，性能评价采用达到指定响应精度的总时间，而非单个计算内核的峰值加速比。

## 二 国内外研究现状与问题分析

文献综述按问题组织，每部分依次说明已有能力、适用条件、尚需检验的问题以及本课题的切入点。

### 2.1 复杂几何建模与特征线离散

1. 梳理 CSG、CAD 面片、贴体非结构网格和体素表示的几何精度、追踪成本与建模要求。
2. 以 OpenMOC 和 MOCkingbird 为代表，区分二维 MOC、轴向挤出的三维或 2D/1D 方法，以及一般三维几何上的长特征线方法[3,6]。
3. 介绍 DDA 体素遍历作为射线追踪基础；明确它解决的是单元穿越与路径长度计算，不自动解决源区覆盖、积分权重和输运误差[9]。
4. 将薄层厚度、孔道宽度、曲率及孔道方向列为需要分析的几何因素。体积保持与表面距离指标作为参考，进一步考察弦长、光学厚度和空腔连通性对响应的影响。

### 2.2 MOC 的 GPU 并行与存储优化

1. 国内已有三维 MOC 的 GPU 加速与性能分析，多 GPU 路线也已有公开研究[4–5,8]；OpenMOC 等提供了相关实现[3]。据此梳理本研究可以继承的执行与验证基础。
2. 比较预存全部轨迹、在线生成轨迹和部分缓存的计算—存储权衡；在线分段和负载均衡已有先例[6,8]。
3. 纳入 NuDEAL 最新研究：分别讨论 MOC/HFEM、DGMOC 与 DFEM-SN 的几何能力、空间近似及显存开销。该文前两类方法仍依赖轴向挤出几何，不能据其框架名称概括为任意三维 GPU-MOC[7]。
4. 采用 Roofline 等性能分析思路区分计算吞吐、访存带宽与数据复用问题，并结合实际分支、归约和迭代成本分析瓶颈[10]。

本部分的切入点：**当几何由规则网格转为局部加密体素后，单元减少带来的收益何时会被不规则追踪、通量累积和迭代开销抵消。**

### 2.3 固定源屏蔽中的自适应与流束效应

- Baker 等已提出面向目标响应的固定源输运网格自适应；国内研究也已利用目标导向多碰撞源和角度求积处理流束问题[11–12]。
- 几何加密、源区加密、轨迹间距缩小和角度加密控制不同误差。仅增加体素数，不能保证缓解离散角方向造成的射线效应。
- 本课题拟进一步研究几何转换引起的路径与连通性误差，并把该误差与 GPU 计算代价联系起来，以区分几何表示误差与既定网格上的解误差。

### 2.4 确定论与蒙卡耦合减方差

- 以 CADIS 的局部响应优化、FW-CADIS 的多响应或分布优化为理论主线，说明正向计算、伴随源构造、伴随重要性、相容源偏倚和权窗之间的关系[13–14]。
- 聚变设施上的 FW-CADIS、自适应确定论网格及权窗网格处理已有研究，为本课题的后续耦合提供直接的方法基础[15]。
- FW/CADIS-Ω 已尝试利用角度信息改善强各向异性条件下的重要性表示[16]。
- Raffuzzi 等的随机射线研究表明，在其两类屏蔽算例中，提高重要性解的物理或空间近似精度未必改善减方差效率；该研究主要考察体屏蔽，明显流束路径仍是后续问题[17]。OpenMC 官方文档已提供随机射线 FW-CADIS 路线，应纳入现实比较基线[18]。

本部分的切入点：**体素几何误差在何种情况下会遗漏重要贡献路径，怎样以较低的正向与伴随计算成本获得有效权窗。**

### 2.5 与拟申请课题组的研究衔接

- VITAS 及其应用研究体现了课题组在通用输运框架、空间—角度离散和基准验证方面的积累[19–20]。
- Yin 等的非均匀介质变分节块并行研究，为并行分解与效率分析提供方法背景；该研究的 heterogeneous 指非均匀介质，不等同于 GPU 异构计算[21]。
- Sun 等的 UVNM-SN 涉及复杂网格、体积修正与非线性扩散加速；迎风 HDG 工作进一步涉及一阶输运方程、多尺度稳定性及扫描求解[22–23]。
- Xiao 与 Zhang 的会议工作已报告 VITAS 上的各向异性散射处理和板状问题验证[24]。

这些工作支持本课题在输运数值方法层面的延续性。拟研究的体素长特征线与 GPU 路线可作为新的几何表示与执行方式，与团队既有方法开展精度、稳定性及成本比较；具体代码模块复用需依据实际可获得接口确定。

## 三 研究问题与研究目标

### 3.1 总体研究问题

**对于薄层材料、曲面界面与斜向贯穿孔道并存的聚变固定源中子输运问题，如何在给定目标响应误差和显存约束下，选择体素几何分辨率与 GPU 特征线执行策略，并确定该方法相对于均匀体素及可复现参考路线的优势区间与失效边界？**

主应用响应选为贯穿孔道后方指定区域的能群中子通量与探测反应率，以检验路径变化对深穿透结果的影响；曲面多层结构及局部包层反应率作为补充验证。

### 3.2 核心研究问题一 体素几何误差如何传递至目标响应

- 体积偏差、界面位移、弦长和光学厚度变化、孔道连通性变化，分别在何种条件下主导响应误差？
- 能否构建兼顾几何特征与输运响应的局部细化准则，在留出几何参数上仍满足误差要求？
- 假设：对输运敏感的薄层与通道实施选择性细化或局部界面处理，有望比全域均匀细化以更少的存储达到同等响应精度。若该优势在未参与调参的算例上不能维持，则需修正或否定此假设。

### 3.3 核心研究问题二 几何表示与并行执行怎样共同决定总成本

- 在线追踪、轨迹分组、能群批处理和通量归约怎样影响访存、负载与源迭代？
- 局部加密在什么规模、方向分布与材料组合下能够缩短总计算时间？
- 假设：以相同响应误差和收敛标准约束算法选择，可得到优于直接移植的执行组合；若单次扫描加快而迭代总时间增加，则不构成有效加速。

### 3.4 拓展研究问题 何种重要性保真度足以改善蒙卡减方差

- 在最终蒙卡保留原始几何的前提下，前向与伴随体素近似应保留哪些信息，才能生成有效的局部或区域权窗？
- 体素 GPU-MOC 的前处理成本，在何种响应类型、衰减程度和重复使用次数下能够回收？
- 该问题在核心求解器通过验证后开展，不把 FW-CADIS 耦合设为前两项研究成立的先决条件。

### 3.5 目标与验收口径

形成几何误差与响应之间的分析方法、可复现的 GPU-MOC 原型，以及适用条件和失败情形明确的验证数据。性能目标用时间—误差—显存曲线表达，不预先承诺固定倍数加速。

拟在算法研究阶段设置 1%、3%、5% 三档目标响应误差进行敏感性比较；这些数值是研究用的候选容差，不是工程验收标准。最终容差应依据所选响应、参考解不确定度和应用需求确定。

## 四 研究内容与研究方法

### 4.1 总体技术路线

原始 CAD/CSG 与材料信息 → 体素化及几何核验 → 全三维轨迹与积分权重 → 多群固定源 MOC → GPU 执行与收敛加速 → 分层误差和成本验证 → 条件性伴随求解与蒙卡权窗生成。

几何表示、材料分区和平源区分别定义。初始实现可令其重合，后续根据误差来源决定是否分离几何分辨率与源近似分辨率。

### 4.2 研究内容一 面向输运路径的体素表示与误差控制

1. **建立最小基线。** 从均匀笛卡尔网格和单体素单材料表示开始，明确材料归属、源区覆盖、边界与坐标规则。
2. **构建几何参数族。** 依次考察曲面多层壳、倾斜薄板、直窄缝和弯曲孔道，改变厚度/体素尺寸比、缝宽/体素尺寸比、方向与曲率。
3. **分离几何误差。** 固定物理源、源强、响应区域及积分或平均口径，以原始几何蒙卡和体素几何蒙卡的响应差异识别几何转换影响，并量化统计不确定度。比较采用相同核数据；若使用多群模型，两侧使用同一套已处理群常数。
4. **建立细化准则。** 联合考虑薄层/连通性几何检查、路径光学厚度变化和初步响应信息。保留独立的几何检查，防止粗输运解因漏掉通道而低估其重要性。
5. **逐级增加复杂度。** 优先评估规则块内局部加密；若其仍不能以合理成本保留关键路径，再评估少量边界子体素或显式界面分段。体积分数混合仅作为比较方案，不预设其能准确保持流束。
6. **验证可迁移性。** 用部分几何建立准则，其余参数作为留出测试；与同等响应误差的均匀加密比较时间、显存与容差失效比例。

### 4.3 研究内容二 全三维体素 MOC 与 GPU 协同求解

**物理模型。** 以稳态、多群、固定源中子输运为起点；逐步纳入各向异性散射及必要的 (n,xn) 二次中子产生。固定源不意味着忽略中子倍增。按已核验版本的 FENDL 等评价库建立数据路径，记录群结构、温度与处理方式[2]。

**输运离散。** 沿三维长特征线实施分段积分，研究轨迹覆盖、积分权重和体积一致性；独立改变体素尺寸、轨迹间距、角度求积与散射阶次。验证无源真空段、有源光学薄区与真空—屏蔽交界的稳定极限，避免用人为小截面代替真空掩盖问题。

**并行组织。** 在冻结源和给定入射条件下，以轨迹—角度—能群批次形成并行工作；同一轨迹保持必要递推，对跨轨迹的同源区累积处理写冲突。比较在线遍历、部分缓存、按路径长度分组和分块归约，记录其各自开销。

**迭代加速。** 依据散射与材料分布评估一种低阶加速或预条件方法；检验其在空腔、强非均匀介质和局部加密条件下的稳定性。收敛困难时保留可信基线求解，不能以放宽精度标准换取表面加速。

**性能分析。** 同时报告几何转换、轨迹准备、数据传输、单次扫描、源迭代次数和总时间，以及峰值显存。采用优化多核 CPU 与单 GPU 的配对实验；多 GPU 扩展仅在单 GPU 内存或时间成为实际限制后开展。混合精度也在双精度基线验证后单独评估。

### 4.4 研究内容三 正向伴随求解与减方差拓展

1. 依据实际离散算子建立伴随形式，纳入体积/角度权、边界映射和群间转移；通过小系统代数对偶与前向—伴随响应一致性验证，而非仅反转轨迹。
2. 先实现单一探测响应的 CADIS，再按多响应目标构造 FW-CADIS 伴随源；保持源偏倚与粒子权重相容[13–14]。
3. 将重要性映射至蒙卡权窗网格，保留对所有可能贡献路径的采样支撑，检查分裂、轮盘赌和长历史行为；最终蒙卡继续使用原始或已验证高保真几何。
4. 比较普通蒙卡、MC 权窗迭代/MAGIC、可运行的随机射线 FW-CADIS 与拟建流程。锁定软件版本和物理近似；算法对比使用匹配模型，工程流程对比另外报告近似差异[17–18]。
5. 以达到指定统计精度的总时间为主指标，辅以 FOM = 1/(r²T_total)，其中 r 为目标响应相对标准误差，T_total 包括群常数准备、正向/伴随求解、映射及蒙卡运行。对空间分布同时报告达标比例和高分位相对误差，并以独立重复运行检查结论稳定性。近零响应或有效计数不足时，采用预先约定的绝对误差尺度，不据单次 FOM 判定优劣。
6. 先研究空间—能量重要性；只有流束算例明确暴露角度信息不足时，才进一步评估角度修正，并以既有 FW/CADIS-Ω 为文献基线[16]。

### 4.5 验证体系与逻辑闭环

| 层次 | 算例与比较 | 回答的问题 |
|---|---|---|
| 基础正确性 | 纯吸收解析题、真空段、多群均匀介质 | 分段积分、守恒、极限和物理转移是否正确 |
| 几何影响 | 原始几何 MC 对体素几何 MC；曲面薄层和孔道参数族 | 体素转换引入了多大响应误差 |
| 离散影响 | 相同体素几何、群常数和散射阶次下，MOC 对多群 MC | 空间源、轨迹、角度与迭代误差是否受控 |
| 聚变相关验证 | 可公开取得的 FNG/FNS 或其他相应基准；代表性包层屏蔽扇区 | 方法能否适用于实际材料和三维结构 |
| 总效率与拓展 | 同精度 CPU/GPU；均匀/局部体素；不同减方差流程 | 性能收益是否覆盖新增前处理与调度成本 |

多群蒙卡对照还需匹配实际群转移、散射角表示及 (n,xn) 二次中子计数方式；参考程序不支持的物理项，先用独立小算例核验。数值解之间的对照属于验证；与公开实验数据比较时，另行考虑源、材料和核数据不确定度，不将全部偏差归因于体素或 MOC。C5G7 可用作通用求解器检查，但不承担聚变屏蔽适用性的主要证据。

## 五 预期创新点

### 5.1 几何转换误差与输运响应之间的关联方法

拟识别薄层和孔道中决定响应偏差的几何、光学与连通性因素，形成局部体素表示选择准则及其失效判据。相对于已有目标响应自适应，重点研究原始几何向体素表示转换所造成的路径扰动，而非仅估计既定网格上的解误差。

### 5.2 响应精度与显存约束下的体素 MOC 执行策略

拟将几何分辨率选择与轨迹生成、数据布局、通量累积和迭代加速联动，建立以完整求解成本为依据的策略选择方法。通过消融与留出算例验证哪些组合有效、何时失效。GPU、DDA、在线追踪或多 GPU 的单独采用不列为创新。

### 5.3 面向流束与深穿透的混合计算适用边界

在核心结果支持的条件下，拟建立体素几何保真度、伴随重要性误差与蒙卡效率之间的定量关系，识别满足给定响应统计要求的低成本重要性近似、适用范围及前处理成本回收条件。已有研究提示重要性精度与效率并非简单单调关系；本研究拟进一步检验具有显著流束路径的几何条件与具体判据。

## 六 可行性与课题组匹配

### 6.1 方法与平台基础

已有 MOC、GPU 输运、体素遍历、伴随减方差理论及公开蒙卡工具可以支撑逐步开发[3–18]。最小实验路线由自建均匀体素 CPU/GPU 配对实现和公开蒙卡参考组成，不以取得全部外部确定论代码为前提。MOCkingbird、NuDEAL 与 VITAS 首先作为文献对照；获得适用接口后再增加可运行比较。

### 6.2 与张滕飞老师研究工作的具体对应

| 课题组已发表工作 | 可衔接的方法问题 | 本课题拟推进的部分 |
|---|---|---|
| VITAS 与基准应用[19–20] | 通用输运离散、空间角度收敛与验证 | 聚变固定源条件下的三维体素特征线表示 |
| 非均匀介质 VNM 并行[21] | 并行分解、计算负载和通信分析 | 体素 GPU 扫描及总成本分析 |
| UVNM-SN 及体积修正[22] | 非结构几何与离散误差、迭代加速 | 路径敏感的体素转换误差及局部表示选择 |
| 多尺度迎风 HDG[23] | 一阶输运、扫描结构和稳定性 | 真空—屏蔽多尺度条件下的 MOC 稳定求解 |
| 各向异性 HVNM 会议研究[24] | 能量角度耦合的离散与验证 | 聚变中子谱条件下的各向异性验证体系 |

本课题与导师的契合点主要在先进中子输运数值算法、复杂几何离散和高效求解。已有公开工作不能替代对本课题所需代码权限、GPU 配额及具体研究安排的确认。

### 6.3 主要风险及备选路线

- **体素几何在极窄通道上失效：** 改用局部界面保留或更细规则块，报告不可接受的成本区间；不强求纯体素在所有几何上占优。
- **空间加密未改善流束结果：** 独立检查轨迹与角度误差，必要时评估未碰撞/碰撞分解，避免继续盲目细化体素。
- **GPU 扫描加快但整体不加速：** 依据时间分解调整累积与迭代策略，暂缓多 GPU 扩展。
- **减方差收益不足：** 优先完成核心方法与适用边界，保留标准权窗作为对照；不以新增复杂耦合掩盖核心性能问题。
- **工程模型或硬件获取受限：** 使用可公开复现的参数几何和实验基准；多 GPU 与完整装置模型作为资源具备后的扩展。

## 七 时间规划与预期成果

按入学后四年拟定，具体培养年限以实际项目要求为准。

| 阶段 | 主要任务 | 阶段成果与推进条件 |
|---|---|---|
| 第 1 年 | 文献与理论；均匀体素 CPU MOC；几何转换；真空、多群与各向异性验证 | 基准集和可信原型；通过守恒、独立收敛及物理转移检查后进入主要性能研究 |
| 第 2 年 | 几何误差参数研究；局部体素表示；单 GPU 实现与性能分析 | 几何误差准则及配对性能数据；在留出算例验证同精度成本收益，记录无优势区域 |
| 第 3 年 | 表示与执行联合优化；聚变相关基准和代表性扇区；条件性伴随模块 | 核心方法与适用边界成果；资源与需求具备时再开展多 GPU；通过伴随一致性检查后开展权窗耦合 |

预期成果包括：一套经过验证的体素 GPU-MOC 研究原型；一组几何—输运误差和计算成本的对照数据；关于局部体素表示与并行执行的可检验方法结论；以及在条件满足时形成的混合减方差模块。论文产出围绕核心问题组织，不预设必须达到的论文数量或性能倍数。
