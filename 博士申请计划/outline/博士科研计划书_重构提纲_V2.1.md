## 一、提纲的总体定位与写作原则

### 1.1 研究方向与范围

本研究围绕三个相互关联的技术要素展开：

- **数值方法：** 以三维、多群、稳态固定源特征线方法（MOC）为基础。
- **几何表示：** 以规则笛卡尔体素为基础表示，局部层级细化作为主要扩展；精确几何求交主要用于参考几何构建和局部辅助，不将多套几何离散体系并列发展。
- **并行架构：** 以单节点 CPU + 多 GPU 异构协同并行为核心，研究节点内 PCIe/NVLink 等互联条件下的任务划分、数据组织、负载均衡、通信和同步。多节点 MPI-GPU 不列为核心研究范围。

主要应用对象为两类聚变屏蔽问题：

1. 多层材料屏蔽：考察材料路径、能谱变化、深穿透通量及指定反应率。
2. 复杂孔道屏蔽：考察孔道连通性、方向性传播、壁面散射及远端响应。

主要评价量为中子能谱、区域通量和指定反应率；中子剂量可作为由通量转换得到的辅助响应。完整中子–光子耦合、氚增殖、磁体核热和停堆剂量不作为基础求解器必须完成的核心任务。CADIS/FW-CADIS 等成熟混合减方差方法只作为条件允许时的应用验证，不发展新的减方差理论。

### 1.2 全文要讲述的核心故事

聚变堆屏蔽结构包含多层材料、薄层、斜交界面和复杂孔道，需要在三维空间内准确计算中子输运。MOC 提供沿特征线求解输运方程的数值框架，但复杂几何的材料表示和射线追踪会带来几何处理成本。体素化能够形成规则、便于索引和组织的材料空间表示，但会引入材料界面和沿程路径近似误差；局部细化有望改善表示精度，却可能增加轨迹段数、源区数量和数据更新成本。与此同时，三维 MOC 的轨迹扫描、通量累积和多群源迭代具有并行机会，也存在负载不均、显存容量和设备间通信等问题。因此，需要研究体素化 MOC 的数值精度控制、CPU–多 GPU 协同计算，以及两者之间的精度–成本协调。

全文形成以下递进关系：

**工程需求 → 数值方法选择 → 体素化几何与 MOC 求解 → CPU–多 GPU 并行 → 聚变屏蔽验证 → 三项研究任务与实施方案。**

三个研究问题的关系为：

- **RQ1：数值精度。** 复杂几何体素表示和 MOC 离散如何影响目标屏蔽响应，如何进行合理的误差评价与空间细化？
- **RQ2：并行效率。** 局部细化和复杂体素几何如何改变轨迹工作量、存储与通信，如何实现单节点 CPU–多 GPU 协同计算？
- **RQ3：精度–成本协调。** 在真实误差未知、搜索预算有限的情况下，如何联合选择体素离散与多 GPU 执行策略，使计算以较低完整成本达到目标响应精度？

RQ1、RQ2 应分别形成可独立检验的方法；RQ3 负责建立误差、工作量、时间和显存之间的联系，不应仅将“联合搜索参数”本身宣称为创新。

### 1.3 章节组织原则

- 第一章论证研究需求与技术路线，不承担详细文献综述。
- 第二章说明几何如何表示、射线如何穿越、体素如何进入 MOC，以及输运方程如何求解和如何评价数值误差。
- 第三章从 MOC 计算流程出发，讨论 CPU/GPU 分工、轨迹存储、GPU 调度和多 GPU 协同，不重复第二章的数值理论。
- 第四章说明具体屏蔽对象、基准和验证依据，不另立蒙卡减方差研究主线。
- 第五章集中提出申请人拟开展的算法、对照实验、验证指标和阶段成果。
- 每章末尾先用一段话归纳本章结论，再用汇总表概括“论证层次/研究环节—核心内容或方法—形成的结论/评价目的”，表格不能只是重复目录。
- 正文主要使用二级标题。具体算法、公式、案例和文献通过段落、图表组织，不为每个知识点增加三级标题。
- 各章之间必须有明确的过渡：上一章得出的结论应成为下一章的研究起点。

# 第一章 研究背景与研究目标

**本章定位：提出问题并论证技术路线。**

**本章叙事：** 从聚变屏蔽的工程需求出发，说明中子输运计算的困难；比较主要输运方法并论证 MOC 的选择；进一步说明复杂几何表示为什么考虑体素化，以及三维 MOC 为什么需要 CPU–多 GPU 异构并行；最后提出研究目标和三个 RQ。

## 1.1 聚变堆中子屏蔽的工程需求与计算挑战

本节回答：为什么需要开展面向聚变堆复杂几何的中子输运研究？

写作顺序：

1. 简要介绍 D-T 聚变中子源及约 14 MeV 中子在聚变装置中的输运特点，说明中子与材料相互作用后会形成散射、俘获和次级粒子等过程。
2. 结合聚变装置结构介绍第一壁、包层、屏蔽体、真空室、超导磁体及维护区域等部件，说明屏蔽计算所服务的工程需求。
3. 从几何角度归纳多层材料、薄壁、斜交界面、诊断孔道和管线穿透件等典型结构，说明材料边界及传播通道对屏蔽响应的影响。
4. 从计算角度提出问题：几何与材料变化要求重新建立材料表示和传播路径；三维多群输运还涉及空间、角度和能量离散，设计方案比较需要控制计算时间。

本节重点是说明工程问题，不提前介绍 DDA、MOC 的详细公式或 GPU 编程机制。聚变装置剖面图用于帮助读者理解工程结构，不作为算法有效性的证据。

**本节落点：** 聚变屏蔽计算需要同时处理复杂三维材料结构和大规模中子输运计算，因而需要选择合适的数值求解方法与几何处理方式。

## 1.2 中子输运数值方法及 MOC 的选择依据

本节回答：采用什么数值方法解决聚变屏蔽中的中子输运问题，为什么选择 MOC？

写作顺序：

1. 给出稳态多群固定源中子输运方程，说明角通量、标量通量、散射源和外源的物理含义。首次出现输运方程应放在本节，不应推迟到第二章后半部分。
2. 简要介绍蒙特卡罗方法、离散纵标方法和特征线方法的基本思想，围绕几何处理、空间与角度离散、统计性质和计算成本进行比较。
3. 介绍 MOC 的基本思想：将空间输运方程沿特征线方向转换为一维沿程问题，通过段内角通量递推和空间角向积分获得标量通量。
4. 说明 MOC 在确定论多群输运、沿材料路径处理和轨迹级并行方面的特点。
5. 指出 MOC 在复杂三维几何下仍需解决轨迹生成、材料分段、轨迹数据存储、源区积分和重复迭代成本等问题。

方法比较应客观，不宣称 MOC 在所有聚变屏蔽问题中优于 MC 或 \(S_N\)。重点论证其作为本研究数值基础的合理性，并将具体适用性留给后续基准验证。

**本节落点：** MOC 提供了沿特征线求解多群输运方程的数值框架，但其三维应用依赖可靠的几何材料分段，并面临较大的轨迹与计算成本。

## 1.3 复杂几何体素化与 GPU 异构并行技术路线

本节回答：为什么考虑体素化，以及为什么需要 GPU 异构并行？

写作顺序：

1. 从 MOC 对材料区间和沿程总截面的需求出发，说明 CAD/CSG 几何直接求交、贴体网格和背景网格映射等几何处理路线。
2. 引出规则体素：通过空间单元和材料编号形成规则化材料场，便于空间索引、材料访问和数组组织；局部层级细化可用于提高薄层和复杂界面的局部分辨率。
3. 同时说明体素化的代价：界面位置和材料段长度可能发生变化，薄层可能失真，窄孔道连通性可能改变，从而影响沿程输运和目标响应。
4. 回到 MOC 计算流程，说明三维轨迹数量、段数、轨迹数据和多群源迭代带来的计算及存储压力。
5. 引出单节点 CPU + 多 GPU 异构并行：CPU 与 GPU 需要协同处理几何管理、任务组织、轨迹计算、通量累积和数据交换；多 GPU 还需处理负载分配、显存管理及 PCIe/NVLink 通信。
6. 用一段话概括本研究技术路线：以规则体素为基础表示，以局部层级细化为主要空间扩展，以三维多群 MOC 为求解框架，以单节点 CPU–多 GPU 为并行架构。

本节只解释技术路线的选择依据，不详细综述 DDA、八叉树、缓存、线程调度和多 GPU 分解；这些分别放入第二、三章。

**本节落点：** 体素化与 GPU 并行分别对应几何表示和计算执行两个层面，但二者共同影响 MOC 的目标响应精度与完整求解成本。

## 1.4 研究目标与关键科学问题

本节回答：本研究最终要解决什么问题？

建议先用一段话明确总体目标：

面向聚变堆多层材料和复杂孔道等典型屏蔽结构，研究体素化三维 MOC 的几何表示与输运响应误差、单节点 CPU–多 GPU 协同并行及精度–成本协调方法，形成具有数值正确性证据和工程应用验证的高效固定源中子输运计算方法。

随后依次提出：

- RQ1：复杂几何体素表示和 MOC 离散如何影响目标屏蔽响应，如何进行误差评价与空间细化？
- RQ2：复杂体素几何下的轨迹工作量、存储和通信如何影响执行效率，如何实现 CPU–多 GPU 协同计算？
- RQ3：如何利用误差与成本信息，在精度和显存约束下选择体素离散与多 GPU 执行方案？

说明研究范围：多群稳态固定源；多层材料和复杂孔道为主要应用；规则体素为基础、局部层级细化为扩展；单节点多 GPU 为核心。完整中子–光子耦合、多节点 MPI-GPU 和新型蒙卡减方差理论不作为核心必达任务。

### 第一章小结

本章应归纳聚变屏蔽的工程需求、MOC 的方法选择、体素化的几何表示价值及 GPU 异构并行的计算必要性，最终形成三个相互关联的研究问题。

建议汇总表：

| 论证层次 | 核心内容 | 形成的结论 |
|---|---|---|
| 工程需求 | 聚变屏蔽复杂材料和孔道结构 | 需要准确、高效的三维中子输运 |
| 数值方法 | MC、\(S_N\)、MOC 的特点 | 选择 MOC 作为数值求解基础 |
| 几何表示 | 原始几何处理与规则体素 | 采用体素表示，同时研究几何近似误差 |
| 计算架构 | 三维轨迹、存储和迭代负担 | 采用单节点 CPU–多 GPU 异构并行 |
| 研究目标 | 精度、性能和资源约束 | 形成 RQ1—RQ3 |

**与第二章的过渡：** 确定体素化 MOC 技术路线后，需要进一步研究原始几何如何转换为材料空间表示、射线如何穿越体素，以及这些几何数据如何进入 MOC 输运求解。

# 第二章 复杂几何体素化与 MOC 数值方法研究现状

**本章定位：建立体素化 MOC 的数值方法基础。**

**本章叙事：** 几何如何表示 → 射线如何穿越 → 体素如何进入 MOC → 输运方程如何求解 → 数值精度如何保证。

## 2.1 复杂几何表示与材料映射方法

本节回答：原始复杂几何如何转化为输运程序能够处理的空间材料模型？

按几何表示与材料映射的发展关系组织文献：

1. 介绍 CAD/CSG 几何表示，说明曲面、实体和布尔运算如何描述复杂部件，以及转换为输运几何时需要保证材料分区完整、无遗漏和无重叠。
2. 介绍贴体网格方法，说明结构化或非结构化计算单元如何贴合材料界面，其几何精度、网格生成和复杂结构处理特点。
3. 介绍非贴体背景网格与材料映射，包括体积分数均匀化、部分填充单元、cut-cell 和嵌入边界等。重点说明原始几何边界与求解网格可以分离，但材料界面信息需要通过映射或局部处理保留。
4. 介绍规则体素材料表示，包括中心点材料标记、材料编号、笛卡尔网格和局部层级体素。说明其规则索引、存储和材料访问优势。
5. 比较不同方法的几何保真度、材料守恒、沿程材料表示、存储需求和计算成本。

代表性程序或团队应作为具体方法的实现证据，不要按软件名单逐个介绍。McCad 等几何转换工作可以说明 CAD 转换和几何核查；ADVANTG、MAVRIC/Denovo 等材料映射流程可用于说明体积分数映射基线，但应准确区分各程序的几何输入和数据流程。

**本节落点：** 体素化提供规则材料空间，但体积平均或中心点标记不一定保留中子沿程经过的材料次序和厚度，后续需要考察射线穿越与材料段生成。

## 2.2 体素穿越与几何界面求交方法

本节回答：给定一条射线，如何准确、高效地得到它经过的空间单元及材料段长度？

按由规则到复杂的顺序组织：

1. 从规则笛卡尔体素出发，介绍射线参数化、网格索引和射线与网格面的交点计算。
2. 介绍 DDA/Amanatides–Woo 快速遍历，说明如何逐体素推进、计算材料段长度并处理面、棱、角交点。
3. 在局部层级细化背景下介绍八叉树或其他层级空间结构，说明叶单元定位、不同层级之间的穿越和粗细网格交界处理。
4. 介绍 BVH 和 CAD 精确求交，说明其用于筛选候选表面和获得精确界面交点的作用。明确 BVH 与 DDA 不是同类算法：前者主要用于层级候选几何查询，后者主要用于规则网格遍历。
5. 说明规则体素穿越为主体、精确几何求交用于参考模型和局部辅助的混合方式，以及其适用条件。

本节重点讨论射线追踪的数值输出：有序材料区间、材料编号、段长和必要的空间索引。面棱角交点、零长度段、重复段、漏段和孔道连通性应作为正确性要求。

**本节落点：** 射线追踪将离散材料空间转化为沿射线排列的材料区间，为 MOC 特征线离散提供几何基础。

## 2.3 体素化几何与 MOC 特征线离散的耦合

本节回答：如何将体素穿越结果组织成 MOC 所需的特征线、积分权重和源区数据？

按 MOC 数据形成过程组织：

1. 介绍 MOC 特征线和角向离散，包括离散方向、射线布置、轨迹间距及角向求积。
2. 说明射线穿越体素后，如何形成有序材料段；材料编号、段长和截面数据如何关联。
3. 区分材料区域、源区和通量计分区：材料区域决定核数据和总截面访问，源区决定源项近似与积分，计分区决定响应统计。三者不必完全重合。
4. 介绍轨迹横截面权重、段长与源区体积积分之间的关系，说明射线积分如何恢复空间通量及其体积求积一致性。
5. 说明局部体素细化对特征线段数、材料索引、源区划分和轨迹数据的影响，以及细化后需要更新哪些几何和积分数据。

本节应建立从体素材料场到 MOC 轨迹数据的完整对应关系，但不提前展开 GPU 缓存和设备间数据传输。

**本节落点：** 体素化 MOC 的核心是把材料空间转换成具有明确方向、材料区间、源区和积分权重的离散特征线系统。

## 2.4 MOC 沿程输运求解与多群源迭代

本节回答：特征线和源区数据准备完成后，如何求解中子角通量、标量通量及多群固定源问题？

第一章已介绍输运方程及 MOC 基本思想，本节展开具体数值求解：

1. 将多群输运方程沿特征线方向转换为一维沿程方程，说明角通量、总角源和入射边界角通量。
2. 介绍平源近似作为基础方法，并适当说明线性源或高阶源近似对空间精度和计算成本的影响。
3. 推导常源、常截面材料段内的角通量解析递推，解释入射与出射角通量关系，以及真空极限和小光学厚度下的数值稳定性。
4. 由出射角通量得到段平均角通量，结合角向求积和轨迹横截面权重计算源区标量通量。
5. 说明多群散射源、各向异性散射和次级中子产生如何进入源更新，介绍固定源迭代及收敛判据。
6. 简要介绍 CMFD 等迭代加速方法的作用，不展开为独立研究方向。
7. 在基本 MOC 求解过程之后，简要比较 Random Ray 等固定源射线类方法，重点说明射线生成、源区积分、统计性质和计算特点。Random Ray 仅作方法比较，不作为本研究主线。

**本节落点：** MOC 通过沿程角通量递推、段平均通量和空间角向积分得到多群标量通量，并通过源迭代完成固定源输运求解。

## 2.5 MOC 数值误差与空间精度控制方法

本节回答：体素化 MOC 的数值误差来自哪里，现有方法如何控制精度？

按误差来源和控制方法组织：

1. 几何表示误差：界面位移、薄层厚度失真、材料体积分数与沿程材料分布差异、孔道连通性变化。
2. 特征线离散误差：射线间距、方向覆盖、轨迹横截面权重和空间积分误差。
3. 源项与角向离散误差：平源/高阶源近似、源区划分、角向求积和散射角展开。
4. 介绍均匀细化、层级网格和已有局部自适应方法，说明几何指标、通量梯度、残差和目标响应敏感性等细化依据。
5. 介绍 DWR 等目标导向方法的基本思想及其在其他输运离散方法中的应用，指出将其用于体素 MOC 时需要构造适当的富集空间缺陷或重构残差，不能直接把已收敛离散方程的代数残差当作空间误差。
6. 归纳体素材料路径误差、MOC 积分误差和目标屏蔽响应之间的联系，并指出局部细化会增加轨迹段数、源区数量和后续计算成本。

核数据不确定度属于物理输入不确定性，应与几何和数值离散误差分开，不在本节混为一谈。

**本节落点：** 现有几何表示和自适应方法为体素 MOC 提供了基础，但复杂界面、窄孔道和目标响应约束下的误差识别与细化成本仍需进一步研究，为 RQ1 提供依据。

### 第二章小结

本章应将几何表示、射线穿越、MOC 离散、输运求解和精度控制归纳为一个完整数值计算过程，说明各环节的输入输出关系，并指出体素化 MOC 中尚需解决的误差与工作量问题。

建议汇总表：

| 研究环节 | 主要方法或内容 | 形成的认识 |
|---|---|---|
| 几何表示 | CAD/CSG、贴体/非贴体网格、规则体素 | 体素提供规则材料空间，但可能改变界面和材料路径 |
| 射线穿越 | DDA、层级体素、BVH/精确求交 | 输出有序材料区间和段长 |
| MOC 离散 | 特征线、材料段、源区和积分权重 | 建立几何表示与输运离散的对应 |
| 输运求解 | 沿程递推、空间积分、多群源迭代 | 获得多群通量和目标响应 |
| 精度控制 | 几何误差、离散误差、局部细化 | 需要面向目标响应评价误差，并考虑细化工作量 |

**与第三章的过渡：** 第二章建立的特征线、材料段、源区和通量计算构成三维 MOC 的计算任务；其轨迹规模、数据访问和迭代过程进一步提出了并行执行和存储管理需求。

# 第三章 三维 MOC 的 CPU-GPU 异构并行计算方法研究现状

**本章定位：建立单节点 CPU–多 GPU 异构并行的计算方法基础。**

**本章叙事：** MOC 有哪些并行任务 → CPU 与 GPU 如何分工 → 轨迹数据如何存储 → GPU 如何调度与归约 → 多 GPU 如何协同 → 如何评价并行效率。

## 3.1 三维 MOC 计算流程与并行特征

本节从第二章的 MOC 数值流程出发，分析可并行任务及其数据依赖：

1. 概括几何预处理、轨迹生成、沿程扫描、源区通量积分、多群源更新和迭代的完整流程。
2. 分析轨迹级并行：不同轨迹在给定源和边界角通量下的计算独立性。
3. 分析方向和能群并行：不同角向、能群任务的并行机会及群间散射耦合。
4. 说明单条轨迹沿程递推的顺序依赖，以及多轨迹对源区通量累积时的全局归约依赖。
5. 归纳轨迹数量、段数、数据读写、通量存储和多群迭代带来的计算瓶颈。

本节不提前讨论具体 GPU 线程参数，而是先从 MOC 算法本身确定并行机会和依赖关系。

## 3.2 CPU-GPU 异构并行与任务划分

本节回答：CPU 和 GPU 如何协同完成 MOC 计算？

1. 简要介绍单节点 CPU-GPU 异构架构、主机内存、设备显存及节点内数据传输通道。
2. 结合 MOC 流程讨论几何预处理、轨迹构建、沿程扫描、通量归约和源更新等任务的设备分配。不得预先断言 CPU 只做几何、GPU 只做扫描，应以代表性程序的真实实现为依据。
3. 介绍主机与设备之间的数据传输、设备驻留、数据复用及显存管理。
4. 介绍异步传输、计算与通信重叠、流水线和同步机制。
5. 比较不同任务划分方式的设备等待、数据传输成本和整体执行效率。

本节先回答设备分工，后续小节再展开轨迹缓存、GPU 调度和多 GPU 通信。

## 3.3 特征线存储与 GPU 显存管理

本节回答：三维轨迹数据规模较大时，如何在有限显存中组织数据？

1. 说明轨迹段长、材料编号、源区编号、轨迹偏移和边界角通量等数据的存储需求。
2. 比较全量轨迹预存与在线生成：前者增加显存和读取成本，后者增加几何追踪计算。
3. 介绍部分缓存和轨迹复用，讨论方向、空间区域或批次等组织方式。
4. 介绍轨迹分批处理、工作区管理和设备显存预算。
5. 介绍连续数组、AoS/SoA 等数据布局及其对访存的影响。

本节应围绕“存储与重建之间的权衡”，不把某种数据布局或缓存规则直接宣称为创新。

## 3.4 GPU 任务调度与负载均衡

本节回答：轨迹能够并行执行，但如何减少线程等待、访存冲突和归约开销？

1. 分析轨迹段数、材料访问次数和源区写入分布造成的工作量差异。
2. 介绍线程、线程块和线程束与轨迹任务之间的映射。
3. 比较原始顺序、按段数排序、按工作量分组和空间区域分组等任务组织方式。
4. 介绍通量累积中的原子更新、线程块局部归约和分阶段归约。
5. 分析任务排序、访存局部性、同步和额外数据移动的成本。

应区分“访问次数多”和“并发冲突高”：源区访问直方图只能作为潜在写入竞争的代理，需要性能计数或实测确认。

## 3.5 单节点多 GPU 协同并行与性能评价

本节是本研究并行方向的重点，回答：如何在单节点内将三维 MOC 计算分配给多个 GPU，并处理设备间数据依赖？

1. 介绍单节点多 GPU 硬件拓扑，说明 PCIe、NVLink 等互联方式及其带宽、拓扑和通信特征。
2. 比较轨迹分解、角度分解、空间分解和能群分解的适用条件。沿程角通量递推具有顺序依赖；角度分解涉及空间通量归约；空间分解可能涉及边界角通量交换；能群分解受群间散射耦合影响。
3. 讨论轨迹、材料信息、源区通量和角通量在多个设备上的复制或分布方式。
4. 介绍跨 GPU 数据传输、通量归约、边界角通量传递、同步及数据一致性。
5. 讨论通信与计算重叠、设备间负载协调和不同互联条件下的执行效率。
6. 说明性能评价应覆盖单 GPU/多 GPU 加速比、强扩展、弱扩展、设备利用率、显存、通信开销和完整输运求解时间。

多节点 MPI-GPU 不作为核心研究内容。单 GPU 是建立正确性和性能基线的必要步骤，但本研究的并行目标是单节点 CPU–多 GPU 协同。

### 第三章小结

本章应总结 MOC 的并行特征、CPU/GPU 任务分工、轨迹存储、GPU 调度和多 GPU 通信之间的关系，指出复杂体素几何会改变轨迹工作量、数据复用和设备负载，形成 RQ2 的研究依据。

建议汇总表：

| 并行层次 | 主要技术 | 解决的计算问题 |
|---|---|---|
| 算法层 | 轨迹、方向和能群并行 | 明确可并行任务及数据依赖 |

# 第四章 聚变屏蔽应用与数值验证依据

# 第五章 研究内容、技术路线与实施方案

**本章定位：提出申请人自己的研究方法与实施计划。**

**本章叙事：** 以 RQ1 解决数值精度，以 RQ2 解决 CPU–多 GPU 协同效率，以 RQ3 协调精度与计算成本，最后通过聚变屏蔽基准完成综合验证。

## 5.1 总体研究思路与技术路线

明确研究对象、物理模型和程序开发边界：三维多群稳态固定源 MOC；规则体素为基础、局部层级细化为扩展；单节点 CPU–多 GPU；多层材料与复杂孔道屏蔽为主要应用。

说明现有程序和课题组基础中哪些模块已经具备、哪些需要扩展，不能将尚未核实的接口或功能写成已具备条件。建立可逐项验证的 CPU 参考实现，并说明其与 GPU 结果比较的前提。

总体技术路线按以下顺序组织：

几何输入与体素映射 → 特征线追踪与材料分段 → 多群 MOC 求解 → 目标响应与误差评价 → CPU–多 GPU 协同执行 → 精度–成本选择 → 聚变屏蔽验证。

## 5.2 复杂几何体素化 MOC 特征线追踪与误差控制

**对应 RQ1：解决体素几何表示与 MOC 数值离散的准确性问题。**

本节先说明研究目标：区分材料几何映射误差与输运积分误差，分析它们对指定屏蔽响应的影响，并在有限资源下合理分配空间分辨率。

拟开展内容：

1. 建立规则体素材料映射和参考几何追踪流程，针对薄层、斜交界面和孔道结构记录材料区间、段长及材料次序。
2. 使用光学路径差异分析几何近似。纯吸收无源情形下可用解析透射关系检验材料路径误差；含散射和体源的多群问题不能直接把光学厚度差当作一般响应误差。
3. 对指定区域通量和反应率，研究正向–伴随敏感性或局部材料扰动，分析材料算子变化对目标响应的影响。
4. 对 MOC 空间离散误差，研究适当的富集空间缺陷、通量重构或独立加密求积，不将已收敛离散系统的代数残差直接当作空间误差。
5. 增加几何保护和覆盖检查，防止粗体素遗漏薄层或封闭窄孔道后，因当前通量很小而错误地判定无需细化。
6. 研究响应敏感性与新增轨迹段数、源区数量及实际扫描工作量相结合的局部细化策略。
7. 通过均匀细化、界面细化、通量梯度细化和响应驱动细化对照，检验误差估计和细化决策是否真正改善目标响应与计算成本。

需要明确：一阶敏感性指标是误差估计依据，不自动构成严格误差上界；细化后必须用实际响应变化和独立参考检查校验估计可靠性。

预期形成复杂体素材料路径与目标响应的误差分析方法、几何保护与响应驱动细化流程，以及可复现的几何和输运验证算例。

## 5.3 面向复杂体素几何的 CPU-GPU 多设备协同并行

**对应 RQ2：解决复杂体素几何下的任务、数据和设备协同问题。**

本节以单节点 CPU + 多 GPU 为核心，研究节点内 PCIe/NVLink 条件下的任务划分、轨迹更新、缓存、负载均衡和通信。

拟开展内容：

1. 建立 CPU 与多 GPU 协同架构，依据 MOC 数据依赖划分几何管理、轨迹准备、沿程扫描、通量累积和源更新任务，不预先限定 CPU/GPU 的唯一职责。
2. 比较轨迹、方向、空间和能群等任务分解方式，分析沿程角通量顺序依赖、空间归约和群间散射耦合对分解策略的限制。
3. 建立轨迹、材料段、源区和边界角通量的数据管理机制，比较全量预存、在线生成和部分缓存。
4. 针对局部细化造成的轨迹变化，研究受影响轨迹定位和增量重建。增量更新必须与全量重建表示同一离散输运问题；几何数据局部更新不代表输运解只需局部更新，多群散射仍可能要求全局重新迭代。
5. 综合轨迹生成、缓存读取、预计复用次数、缓存失效和维护开销，研究显存预算下的缓存选择。
6. 研究非均匀轨迹工作量下的多 GPU 动态任务分配，结合设备计算能力、轨迹段数和空间访问特征进行负载均衡。
7. 研究跨 GPU 通量归约、必要的边界角通量交换、PCIe/NVLink 传输、同步和通信计算重叠。
8. 通过 CPU/GPU 一致性、单 GPU/多 GPU 比较、全量重建/增量更新对照、消融实验和强弱扩展评价，验证方法收益。

预期形成面向复杂体素 MOC 的 CPU–多 GPU 任务划分、轨迹管理与设备协同方法，并明确不同几何、硬件和迭代条件下的适用范围。

## 5.4 体素离散与多 GPU 执行的精度–成本协同优化

**对应 RQ3：解决离散精度与多 GPU 执行策略之间的协调问题。**

本节不把“联合搜索参数”本身作为创新，而是研究在真实参考误差未知、完整试算成本较高、搜索预算有限时，如何利用物理误差指标和计算成本模型选择达标方案。

拟开展内容：

1. 定义体素离散参数、MOC 轨迹与源区参数、多 GPU 执行参数及其可行范围。
2. 区分离散误差、同离散 CPU/GPU 实现差异和参考计算不确定度。研究验证阶段可使用高精度参考值，但实际选参不能假定预先知道真实误差。
3. 利用 RQ1 的几何路径、响应敏感性和富集缺陷构建可在运行时计算的误差指标，并通过高精度参考算例校准。
4. 利用 RQ2 的轨迹工作量、缓存、访存、通信和同步特征构建时间及峰值显存预测模型。输入特征应能在完整求解前或少量试算后获得。
5. 在响应误差、实现差异和显存约束下，生成有限候选离散与执行方案，利用成本预测和必要的实际试算进行筛选。
6. 比较联合选择、强两阶段选择、等预算直接搜索；小规模算例可用完整枚举作为参考。
7. 将模型校准、参数搜索、轨迹更新、输运迭代和最终复核的开销纳入完整达标成本，评价一次性计算与重复设计扫描时的收益差异。
8. 在未参与模型校准的薄层、孔道尺寸、界面倾角及几何类型上开展独立验证，报告成本预测误差、达标率、错误达标率和完整求解时间。

预期形成误差和成本可解释的有限预算选参方法，明确联合选择相较独立选择的实际收益条件，而不预设联合优化必然更优。

## 5.5 数值验证与聚变屏蔽应用方案

将第四章已有基准依据转化为本研究实际采用的验证任务：

- 基础解析算例：均匀纯吸收体、多材料平板及可解析输运问题。
- 复杂几何算例：斜交薄层、直通孔道、折弯孔道和局部层级细化。
- 数值验证：材料段、积分权重、守恒、空间/角向收敛及多群源迭代。
- 并行验证：同一离散下 CPU/GPU 比较，单 GPU/多 GPU 比较，增量更新/全量重建比较。
- 性能验证：轨迹生成、扫描、归约、通信、源更新和完整迭代的分项计时；显存和设备利用率。
- 应用验证：选择输入完整的 FNS 材料和孔道基准，报告逐测点响应、C/E、实验不确定度及蒙卡统计不确定度。
- 协同优化验证：与强两阶段方法和等预算搜索比较，并在独立几何上评价达标可靠性。

所有性能比较固定物理模型、数值离散和收敛准则；所有实验比较明确源归一化、核数据、探测器响应和统计不确定度。不能把实验 C/E 直接解释为体素化误差，也不能把 GPU 内核加速比代替完整求解收益。

## 5.6 研究计划与阶段成果

按四年安排，允许基础程序、几何验证和 GPU 基线交叉推进：

| 阶段 | 主要任务 | 阶段成果与进入下一阶段的依据 |
|---|---|---|
| 第一年 | 核查现有程序基础；建立或完善 CPU-MOC 参考流程；完成规则体素、材料追踪、源区积分和基础解析验证 | 可复现的数值基线；材料路径和体素误差数据；基础输运计算通过正确性检查 |
| 第二年 | 开展目标响应误差分析、几何保护和局部细化；建立 GPU 基础实现和 CPU/GPU 一致性验证 | RQ1 方法原型及独立几何验证；单 GPU 正确性和性能基线 |
| 第三年 | 重点开展 CPU–多 GPU 任务划分、轨迹管理、增量更新、负载均衡和跨设备通信；建立成本与显存模型 | RQ2 方法和性能证据；RQ3 初步预测模型与协同选参框架 |
| 第四年 | 完成独立几何测试、精度–成本协同优化、FNS 材料与孔道基准验证及综合性能评价 | RQ3 独立验证；完整应用结果；论文与博士学位论文 |

阶段成果不以软件功能数量作为唯一标准，应包含可检验的方法、对照结果、误差和成本证据。

## 5.7 预期创新与研究可行性

预期贡献围绕三项研究问题表述：

1. **数值方法贡献：** 复杂体素几何中材料路径变化与目标响应误差的评价，以及结合几何保护和响应信息的局部离散控制方法。
2. **并行计算贡献：** 面向复杂体素 MOC 的单节点 CPU–多 GPU 轨迹管理、任务调度、数据协同与通信方法。
3. **协同优化贡献：** 面向目标响应精度和显存约束，利用误差与成本模型进行离散和多 GPU 执行方案选择的方法。

可行性论证应分别说明已有程序基础、CPU 参考实现、多 GPU 硬件条件、核数据与实验基准来源。风险分析应对应具体替代路径：伴随接口不足时先做局部扰动敏感性；增量更新收益不足时保留全量重建；多 GPU 通信成本过高时调整分解策略；误差预测泛化不足时明确适用范围并加强独立复核。

### 第五章小结

本章应将 RQ1、RQ2、RQ3 分别对应到具体算法、对照和验证，说明三者如何共同形成面向聚变复杂几何屏蔽的体素化 MOC 与 CPU–多 GPU 高效计算方法。

建议汇总表：

| 研究问题 | 核心研究方法 | 关键验证 | 预期贡献 |
|---|---|---|---|
| RQ1：数值精度 | 材料路径分析、响应敏感性、几何保护和局部细化 | 解析问题、复杂界面和孔道独立算例 | 体素化 MOC 误差评价与离散控制方法 |
| RQ2：异构并行 | CPU–多 GPU 任务划分、轨迹增量更新、缓存和负载均衡 | 同离散一致性、设备通信、强弱扩展和消融 | 单节点多 GPU 协同计算方法 |
| RQ3：精度–成本协调 | 误差预测、时间/显存模型、有限预算选择 | 强两阶段基线、等预算搜索和未见几何测试 | 可解释的精度–成本协同选择方法 |

## 四、文献、图表与正文写作要求

1. 文献按研究问题和技术方法组织，不按作者或软件逐篇罗列。每段先提出问题和方法，再用代表性程序、团队及结果支撑，最后说明适用条件或与本研究的关系。
2. 区分正式期刊论文、会议论文、技术报告、程序手册和预印本。性能数字必须核对原文中的硬件、几何、能群、基线和计时边界。
