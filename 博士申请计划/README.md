# 博士申请计划

## 当前工作基准

- **结构依据：** [博士科研计划书重构提纲 V2.1](outline/博士科研计划书_重构提纲_V2.1.md)。
- **当前 LaTeX 基线：** [latex/main.tex](latex/main.tex)。该文件目前仍是 V5.3 原稿，后续将在 develop 分支依据 V2.1 提纲进行大范围重构；本次归档没有改动正文。
- **当前正式旧版 PDF：** [V5.3 PDF](exports/博士科研计划书_V5.3.pdf)，仅作为重构前基线，不代表新提纲下的最终稿。
- **历史版本：** [archive/README.md](../archive/README.md)，按版本顺序保存 V4.2、V5.2、V5.3 深化版、V5.3 正式版及 V5.3 批注修订版的文件快照。

## 后续工作约定

1. 新正文以 V2.1 提纲为结构依据，不机械搬运 V5.3 旧段落。
2. 旧版 LaTeX、PDF、图源、参考数据及批注记录在 archive 中保留，供核对和选择性复用。
3. develop 为重构开发分支；main 保留当前 V5.3 正式基线。未经明确授权不将 develop 合并到 main。
4. 新正文重构时，逐项核对文献来源、公式、图源和数据；旧版本中的结论不因被归档而自动视为已重新核验。
