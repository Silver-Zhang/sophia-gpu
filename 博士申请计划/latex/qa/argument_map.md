# 六章论证与段落契约

1. 动机：薄层/孔道的材料路径与大规模扫描产生共同精度和资源约束。输入为聚变响应及输运方程；只提出问题，不预报优势。
2. 几何证据：CAD/CSG—体素—射线区间；DDA/八叉树/BVH的输入输出；原文误差与成本；明确SN/MC到MOC的可迁移操作及边界。不写成软件目录。
3. GPU证据：同一论文的问题、轨迹/存储/任务、硬件、结果与基线。将不同加速口径放表中，不组成排名。结论只到待测机制。
4. 方案：RQ1路径/光学厚度误差；RQ2缓存、任务和累积；RQ3联合精度/显存/时间约束。每节列依据、假设、对照、变量、指标、判断标准。
5. 验证与应用：解析—离散收敛—CPU/GPU—实验—工程—CADIS应用。保留响应恒等式、偏倚归一化、多目标伴随源及FOM。新算法先经过确定论验证再进MC。
6. 阶段：基线与权限核对—空间误差—GPU—联合优化—应用/论文；预期知识产出和资源不足的可执行收缩。

文风：事实、推论、假设分别使用“报告/说明”“据此判断”“拟检验”；不把功能开发列为创新。无证据的硬件、轨迹数量和显存字段保留“未获得”，不估计补齐。
